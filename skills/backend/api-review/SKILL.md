# 接口改动审查

## 逐项检查

1. **鉴权** —— 每个新端点都显式声明权限，不能靠"路由前缀拦过了"默认安全
2. **幂等** —— 写操作被重放会怎样？支付/扣减/发号这类必须有幂等键
3. **错误语义** —— 参数错是 400，没权限是 403，不存在是 404，冲突是 409。别全用 500
4. **分页** —— 任何可能返回集合的接口都要有上限，默认值不能是"全部"
5. **破坏性** —— 改字段名/类型/必填性时，先 grep 所有调用方

## 输出

按严重程度排，每条给 `文件:行号` 和一句修法。没有问题的类别写"无"。
