# 界面改动审查

## 逐项检查

1. **状态齐全** —— 加载中 / 空 / 出错 / 部分失败，四个都要有，不能只有成功态
2. **可访问性** —— 键盘可达、焦点可见、图片有替代文本、颜色不是唯一信息载体
3. **边界** —— 超长文本截断还是换行？数量为 0 或 1000 时什么样？
4. **响应式** —— 最窄断点下会不会撑破

## 输出

按严重程度排，每条给 `文件:行号` 和一句修法。没有问题的类别写"无"。
